SouthCoast Eats V2 Consumer UI Baseline
Date: 2026-09-18

This package pins the tested current UI source to Git commit/blob:
37d991a9b1d52a2e7b7b046d05f4feb9ff49e243

The index.html is intentionally a small baseline loader. It fetches that exact
verified UI version and applies the service-filter fixes at runtime, so uploading
this file to main does not depend on an older local ZIP or an unpinned main-branch
copy of index.html.

Service-filter fixes:
1. Main recommendation: selected service is a hard filter; no service fallback.
2. Surprise Me: selected service remains a hard filter.
3. Cheaper: selected service remains a hard filter.

Do not reconstruct the consumer UI from older handoff ZIPs. This pinned baseline
supersedes the older UI exports.
